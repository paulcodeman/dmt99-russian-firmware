# Changes

## 0.1.0

- Russian replaces the Chinese language slot in the exact stock DMT-99 V2.4 image.
- English remains available; both UI layouts are supported.
- Rendering-only overlay with an embedded Cyrillic font and no external Flash writes.
- Hash-locked inputs, instruction-level UI checks, IPS releases and a standard-library-only BIN creation utility.
- GitHub Actions builds and verifies pushes/PRs; version tags publish experimental prereleases.
- Physical startup, analog accuracy and bootloader recovery are not confirmed.
