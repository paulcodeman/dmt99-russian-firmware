# DMT-99 V2.4 RU / EN — экспериментальная модификация

Русский язык заменяет китайский пункт. Английский сохранён. Обе темы переведены.
Надстройка рисует текст сама: изменять внешнюю память с картинками не требуется.
Штатный загрузчик остаётся без изменений.

## Получить готовый BIN

Нужен Python 3.10 или новее. Распакуйте архив и выполните из его каталога:

```powershell
python make_firmware.py
```

Программа скачает официальный образ FNIRSI, проверит его SHA-256, применит
патч и проверит результат. Рядом появится **DMT99RU.BIN**. Компилятор не нужен.

Если официальный файл уже скачан:

```powershell
python make_firmware.py --original DMT-99_V2.4_20240306.BIN
```

Программа сама не обращается к мультиметру. На BOOT должен попадать только
один выбранный BIN, а не IPS, overlay.bin или весь архив. Для обновления
используется штатный режим POWER + AUTO/MENU и порядок, показанный загрузчиком.
В версии приложения после установки ожидается подпись **DMT 2.4RU**.
В меню языка доступны «Русский» и English.

## Проверки и ограничения

Проверены реальные инструкции надстройки совместно со штатными функциями:
128 сочетаний состояния меню, темы и языка; переключение языков; 44 изображения
с китайскими подписями; сохранность стека и регистров; смысл выделения кнопок
«Назад» и «Сбросить». Аппаратные операции заменены программным экраном.

**Физический запуск и точность измерений не подтверждены.** Это экспериментальный
кандидат. Сохраните официальную V2.4: возврат возможен через работающий загрузчик,
но восстановление после неудачного обновления не гарантировано.

IPS — патч полного приложения, а overlay.bin — только наша добавленная часть.
Ни один из этих двух файлов нельзя загружать как прошивку.
